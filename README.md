# Cat Bot (Slack Bot)

This is Cat Bot, a simple 24/7 slack bot to get a random quote every time you run a command.

There are three commands built in:
- /cat-quote: returns a motivational quote.
- /cat-boost: motivates you to keep going.
- /cat-focus: returns a tip to stay concentrated.

It's already running 24/7 on Slack in the Hack Club workspace (hosted on my own private VPS). You can check it out!

# Made for Stardance - Hack Club

**Language**: Python3
**Framework**: slack_bolt
**Deployment**: systemd

Clone the repo, add your variables **SLACK_BOT_TOKEN** and **SLACK_APP_TOKEN** in .env variables and you're all set!
